# 🌱 Smart Green Campus Management System

### Building a Smarter, Greener and More Sustainable Campus

## 📌 About the Project

The **Smart Green Campus Management System** is a technology-driven application designed to support smarter and more sustainable campus management.

The project aims to simplify campus-related management activities while promoting environmental awareness and efficient resource management through a digital platform.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Kulsumfariya173/Smart-Green-Campus-Management-System.git
```

### 2. Navigate to the project folder

```bash
cd Smart-Green-Campus-Management-System
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Open the local URL displayed in your terminal.
